# Restaurant & Cafe Templates

Template website untuk menampilkan menu digital, reservasi, dan delivery order integration.

## Fitur Umum

- Menu digital dengan kategori
- Gallery foto makanan
- Reservation/booking meja
- Delivery order integration
- Promo & special offer
- Customer reviews
- Location & jam operasional
- Responsive design

## Template yang Tersedia

### Template 1 - Modern Restaurant
Modern design dengan menu showcase dan booking system.
- Features: Menu grid, Gallery, Reservation form, Reviews
- Tech: Next.js, Tailwind CSS, TypeScript

### Template 2 - Deny Restaurant
Artisanal modern restaurant dengan bilingual system (ID/EN), menu detail multi-foto interaktif, sistem profil kru & koki (Staff showcase), ulasan WhatsApp langsung, dan gambar teroptimasi WebP.
- Features: 34 Menu items, Dynamic slug details, Interactive 3-photo rotating gallery, Staff roster & Founder spotlight, Bilingual switch (ID/EN), Direct WhatsApp review, WebP assets
- Tech: Next.js 15, React 19, Tailwind CSS v4, Framer Motion, GSAP, Lenis, TypeScript
